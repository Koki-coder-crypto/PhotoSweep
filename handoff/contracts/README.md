# 実行できる仕様の参照モデル
`policy.mjs` は課金や写真APIを操作しません。仕様上の「許可する/しない」をテストするモデルです。
`node --test contracts/policy.test.mjs` で56項目を確認できます。

これはネイティブの安全性、StoreKit検証、永続化、実機の振動を証明しません。
`recordDecision` は永続化の成否を入力として受け取る参照関数です。実アプリでは事前の枠確認と永続化を同一トランザクションにし、保存後にだけ表示・触覚を確定してください。
日付バケットの更新、時計変更、日跨ぎ、assetの消失と権限変更、trial対象者判定そのものは別途実装・テストが必要です。
商品が1週以外の体験に設定されている場合、モデルは7日体験を表示しません。公開設定の受け入れテストは「1week」であることを確認し、不一致のまま公開しないでください。

`acceptance-scenarios.json` の全シナリオは **NOT_RUN** です。Codexが実アプリで実施した結果とログを別ファイルに残します。
`interfaces.ts` は責務の境界だけを示します。Expo/StoreKitのAPIの実在を保証するコードではありません。
