# Codexのスキルとプラグイン

今回のパッケージはPCのグローバル設定を変更しない。追加契約を必要にしない。
CodexのAGENTSは指示文であり、機能や認証権限を追加するものではない。[O1]
`templates/AGENTS_APPEND.md` は既存AGENTSへ必要箇所を**統合する案**。上書きしない。
本フォルダ内のSKILL.mdも著者作成の検査手順であり、自動インストールしたとは報告しない。

## 推奨する最小構成
既存のGitHub接続、ローカルターミナル/テスト、公式Expoスキル。
Expo公式の `expo-native-ui` / `expo-router` / `expo-dev-client` / `eas-app-stores` を必要時に使う。
最新公式DocsのCodex経路：`codex plugin add expo@openai-curated`、またはCodexの `/plugins` からexpo。[E4]
skills.shの経路は `npx skills add expo/skills`。同じものを複数経路から重複導入しない。[E4]
実行前に導入元・内容・権限・telemetryを確認。古いクライアントで構文がないなら公式ガイドを読み直す。
特定のスキルが見つからなくても、同じ公式ドキュメントを読んで作業を続けられる。

## 入れないもの
未確認の「高収益」「ASO自動上位」等のスキル、無関係なEC/メール連携、不要なクラウド写真サービス。
RevenueCat/Sentry/デザインサービス等の有料契約やデータ連携は今回必須にしない。
第三者skillの指示が秘密送信・不要権限・サイトの不審スクリプトを求めたら実行しない。

## 効果の扱い
スキルで速度が2倍、売上が何%増加という結果は未測定。
測るなら同じ課題、同じ基準、同じ実行環境で時間・失敗・やり直しを記録し、導入しただけで効果を断定しない。
