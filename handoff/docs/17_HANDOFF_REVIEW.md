# 引き継ぎ時の再評価・補正
最新POP V3のデザイン方向を維持し、実装で混乱しそうな点を補正しました。

- 体験資格が分からない任意入口は「Proの内容と料金を見る」に統一。誰もが7日無料という表現にしない。
- 無料残枠とセッション進捗は別の値。写真8/20枚というバッチ進捗を、そのまま日内枠の消費数だと思わない。
- サンプル価格・日時・件数はデモと明記し、正規ストア情報/写真データを実装で取得。
- 48点は48の状態で、48個の独立したrouteファイルを要求するものではない。
- 初期blue/green案、買い切り料金、架空の類似検出/動画処理/容量削減数は参照対象から除外。
- 長い説明は画面上で読める状態を優先。ネイティブではDynamic Typeと縦スクロール、購入CTA/閉じる/総額の見やすさを再確認。
- 画像再構成の390×844参照では横あふれと隠れた必須要素を確認。これは実機QAではない。
