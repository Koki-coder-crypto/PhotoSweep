# 日本語と表示の一貫性

本文は `design/copy.ja.json` を起点に、各specの動的条件を適用。画像中の文字をOCRでコピーしない。
サンプルの金額・日時・件数は、実装ではセレクタ/ストアから置換。
短く具体的に。「さらなる体験」「思い出を解放」「スマホも心も軽く」「人気No.1」「今すぐ最適化」は不要。

| 場面 | 採用 | 避ける |
|---|---|---|
| 候補へ | 削除候補に入れました | 削除しました（まだ消していない） |
| 誤操作 | 1つ戻す | 取り返しがつかない（候補段階） |
| 見直し完了 | 20枚、見直せました | 1.8GB空きました（未測定） |
| 削除前 | この6枚を削除しますか？ | この6枚で、大丈夫？だけで目的不明 |
| 全部残す | 削除候補はありません | 残しておきたい写真でした（気持ちを決めつける） |
| 料金 | 7日後から{総額}/{期間}で自動更新 | 無料、だけを強調 |
| 試用後 | Proが使えるようになりました | 購入ありがとうございました（まだ無料体験） |
| 資格不明 | 対象を確認中 | 誰でも7日間無料 |
| 写真なし | 表示できる写真がありません | まだ、写真がありません（原因断定） |

成功/状態画面で同じ見出しをheaderと本文に二重に大きく置かない。
「候補」を一般ユーザーが理解できるよう初回だけ「削除するか最後に確認する写真」と説明。
「残す」はiOSのお気に入りではなく、PhotoSweepでの判断記録。
プライバシーは「開発者に写真を送らない」。iCloudやStoreKit通信があるので「一切通信しない」とは書かない。
法的文面と運営者情報は実際の運用に合わせて公開前に確定する。
