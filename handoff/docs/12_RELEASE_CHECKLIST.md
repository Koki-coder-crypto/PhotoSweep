# Release gate（未実行項目は未実行のまま）

- [ ] 実依存が整合、型検査とExpo診断に成功
- [ ] 本番関数を直接テスト、失敗を消していない
- [ ] 48参照状態と追加バリアントの到達を確認
- [ ] 候補追加では消えず、iOSの確認後だけ削除
- [ ] 保存失敗/削除中断/一部失敗/権限取消でデータを壊さない
- [ ] 無料50枚の定義と画面の数字が一致
- [ ] StoreKitの商品・資格・権利・期間の検証
- [ ] 対象外と確認中に無料体験を約束しない
- [ ] 年額総額と自動更新が読みやすい。閉じる/無料継続/管理あり
- [ ] 復元、解約、失効、返金/取消、grace、旧購入に対応
- [ ] テストの擬似権利・デモ写真・画面catalogがReleaseで有効にならない
- [ ] ロック画面通知に写真の内容・枚数を出さない
- [ ] 写真アップロードなし。計測SDKを未承認で追加していない
- [ ] VoiceOver、大文字、44pt、Reduce Motion、音/振動オフ
- [ ] metadata/権限文/規約/privacy/問い合わせが実装と一致
- [ ] プライバシーmanifest、必要理由API、実SDKの収集項目を監査
- [ ] 実iPhoneとStoreKit sandboxのログあり
- [ ] 秘密・個人写真・フォントファイルがcommitに含まれない
- [ ] オーナーが料金・試用設定・提出内容を承認
- [ ] 提出/公開の明示承認を得た

審査通過や収益は保証しない。Appleの最新レビュー指針、サブスクの継続価値、メタデータ要件も提出時に再確認。[A5]

## 完了報告の形
実装済 / 自動検証済 / native実機検証済 / Apple設定待ち / 公開未実施を分ける。
ビルド番号、コミット、コマンド、スクショとログ、残るリスク、本人に必要な操作を短く書く。
