# Motion / Haptics

## 感触
写真が指に追従する→一定距離でラベルが明瞭になる→離して確定→カードが収まり次が出る。
左は候補・右は残す。軽い振動は同じ強さ。写真を多く消した方が報酬が強くなる設計にしない。

| 動作 | 仮の設計 | 条件 |
|---|---|---|
| ボタン押下 | scale 0.975、110ms | 実測で調整。文字/領域は崩さない |
| スワイプ | ±7°以内、30%幅で確定の目安 | 横/縦gestureの競合を防ぐ。途中で戻せる |
| カード退出/復帰 | 160〜220ms | JSスレッド重処理を避ける |
| 決定 | light haptic 1回 | 永続化成功後、keep/candidate同じ |
| 区切り完了 | check 360ms、紙吹雪≤650ms/14粒 | 自動で次の20枚へ突入しない |
| ネイティブ削除成功 | success haptic 1回 | OS結果確認後、実際に成功したとき |
| 失敗/キャンセル/課金提案 | 成功の触覚なし | 警告を触覚だけで伝えない |
| Pro開始 | 短いcheck | 権利検証後、無料体験を有料購入完了と呼ばない |

数値は目標・仮設定で、心地よさを測定済みではない。
expo-hapticsの標準APIをまず使う。呼び出せても端末状態で振動しない場合がある。[E2]
Reduce Motionは端末設定を優先し、フェード120ms程度へ。回転・跳ね・紙吹雪を省く。音は初期オフ、振動はいつでもオフ。
写真に個人的な内容があるので勝手に効果音を鳴らさない。音を有効にした場合もサイレントモードとアクセシビリティを尊重。

## 実機評価
連続100回の操作で引っかかり・二重確定・ボタンの移動がないか確認。
写真数1,000件、低電力、iCloud写真、発熱時などを記録。フレームレートやms目標は実測した値と分ける。
44pt以上のhit target、VoiceOverの「削除候補にする」「残す」「前の操作を戻す」、ピンチ以外の拡大手段。

`design/animation-preview.html` は方向とテンポを示すブラウザ上の説明モデル。iPhoneの触覚や性能のテストではない。
