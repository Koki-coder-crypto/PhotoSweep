# Scope / 決定事項

| 機能 | 無料 | Pro・体験中 |
|---|---|---|
| 月別・スクショの一覧 | 全期間、許可された写真 | 同じ |
| 新しい写真の仕分け | 1日50枚 | 枚数上限なし |
| 1回の目安 | 20枚、残枠/写真数で短縮 | 20・50・100枚、途中終了可 |
| 日付の自由指定・古い順/新しい順切替 | 月別と固定の並び順 | あり |
| 写真の拡大、候補確認、取り消し | あり | 同じ |
| 既に選んだ候補の削除 | 上限到達後も無料 | 同じ |
| 自動保存・再開・ヘルプ | あり | 同じ |
| 通知・振動設定・契約管理 | あり | 同じ |
| 整理の記録 | 端末内の実績 | 同じ |

「50枚」「20枚」は初版の仮設定。最適な課金率を実測済みではない。configurationの1箇所で管理し、実験時は表示と判定を同時更新。

## 初版から外す
AI類似検出、重複の自動判定、自動削除、動画圧縮、メール／連絡先整理、クラウドへの写真アップロード、アカウント登録、SNS共有、ランキング、Apple Watch、ウィジェット、広告SDK、優先サポートの約束。
旧コードに残る類似・large・oldの推定機能を、新UIへ自動露出しない。

## 変更点
旧「30枚まで無料で削除」「一度2,480円払えば永久」「isProを保存して終了」は不採用。
直近の「1日50枚の仕分け・月額/年額と7日体験」を正とする。
全48PNGの金額・日時はデモ。製品ではStoreKitの値。
サブスクが本当に事業として持続するかは公開後に検証。解約のしにくさや無意識の更新に依存しない。
