## 現在の状態

## ビルドとインストール

1. `eas login --browser` を公式画面で完了。パスワード・2FAはチャットに貼らない。
2. `eas whoami`、`eas account:usage --json --non-interactive` でログイン・プラン・無料残量を確認。有料実行になる場合は中止。
3. `eas init` で既存プロジェクトに接続または作成し、返されたIDを `EXPO_PUBLIC_EAS_PROJECT_ID` に設定。
4. Bundle ID `com.kokicoder.photosweep` をApple Developerで確認。未使用なら登録。Appleの認証・署名設定は本人の公式画面で実施。
5. `eas device:create` のリンクをiPhoneで開いて端末登録。その端末を含むプロファイルで `npm run build:development`。
6. 完了したビルドURLからiPhoneへインストール。開発者モードが必要なら端末上で有効化。`npm start` を実行して開発ビルドから接続。
7. `eas build:list --platform ios --limit 5` でbuild IDを記録。バイナリの生成成功・実機起動まで確認。

無料枠がなくなった場合、追加のビルドを行わずローカルの修正・検証を続けます。WindowsではXcodeコンパイル・iOS Simulatorを実行できません。

## 写真検証

本人が用意した、削除してよいテスト写真だけを使用します。個人写真をログ・スクリーンショットへ残しません。

- 全アクセス、選択写真のみ、拒否、端末制限。選択写真を追加・取り消して復帰。
- 0/1/19/20/21枚、スクショのOS分類、複数の月。iCloudのみの写真と通信断。
- 仕分け→取り消し→再判断→終了→アプリを強制終了→再開。同じ写真・残数・位置を確認。
- 49→50→51枚。上限後に候補・取り消し・削除を使えること。日跨ぎ・タイムゾーン変更。
- 候補だけでは原本が消えないこと。候補一覧で1枚外し、拡大して確認してから削除。
- OS削除確認をキャンセル。全成功、権限取消、削除中終了→再起動。削除が勝手に再実行されないこと。
- Appleの写真アプリから「最近削除した項目」のテスト写真を復元。

大量写真のページ取得・メモリ・iCloud待機時間は端末で測定します。Windows上で10,000件を保存できたことは、実機の10,000写真読み込み性能を意味しません。

## StoreKit Sandbox

App Store Connectに日本語アプリを登録し、同一サブスクリプショングループへ月額/年額の2商品を作成。候補価格は月480円・年2,400円、対象者7日無料。実際の価格と資格はAppleの設定を確認して確定します。Sandbox用アカウントを使用し、実課金はしません。

- 対象/対象外/資格不明、オフライン、取得失敗。固定料金への置換がないこと。
- 月額/年額のID、請求総額、更新条件、無料のまま閉じる、OS購入キャンセル。
- trial開始、更新、自動更新停止、失効、返金/取消、猶予期間、請求再試行。
- Ask to Buy/保留。保留中にProを偽装しないこと。後から承認/拒否されたときの表示。
- 復元、復元対象なし。未検証の取引・旧ローカルisProで解放しないこと。
- 無料枠を使った日のPro開始/失効後、元の無料残数を維持すること。

旧買い切りは未公開・購入者なしという前提のため新規販売しません。互換コードの正規権利復元は、実商品が存在する場合に検証します。

## 操作感とアクセシビリティ

100操作を連続で行い、引っかかった操作番号、読み込み待ち、意図と違った判定、OS/アプリ版、低電力状態を記録します。スワイプ閾値はカード幅30%、通常退出190ms。保存成功後の触覚・音、失敗時のカード復帰を確認します。Reduce Motion・触覚オフ・音オフ・大きな文字・VoiceOverでも主要操作が使えるか確認します。

Webでのボタン連続操作を、実機のスワイプFPS・触覚検証と同一視しません。
