# App Store説明原稿（日本語・未提出）

名前：PhotoSweep
サブタイトル：似た写真・スクショをまとめて整理
カテゴリ候補：写真／ビデオ

撮りためた写真を、見比べて整理。
似ている写真、同じ画像、スクリーンショットから探して、いらない写真を選ぶだけ。

・写真を並べて比較し、まとめて選択。
・削除前に写真を拡大して確認。
・1枚ずつ見たいときは月別スワイプ。右に残す、左に削除候補。
・迷ったらスキップ。取り消しも、中断した作業の再開もできます。
・選択だけでは消えません。削除ボタンを押したあと、iPhoneの確認を経て削除します。

写真の解析は端末内で行い、開発者のサーバーへ送りません。アカウント登録や広告SDKはありません。類似判定は提案です。iCloudのみの写真など、解析できない写真があります。原画像を表示する際に通信が必要な場合があります。

無料で1日30枚の写真と5本の動画を仕分けできます。保存済み候補の確認・削除・取り消し・保存は上限後も無料です。

PhotoSweep Proは枚数制限を解除し、期間指定・並び替え・20/50/100枚のスワイプ区切りを利用できます。自動更新プランと買い切りプランを提供予定です。実際に購入できるプラン・価格・無料体験の適用条件はアプリ内のApp Store情報をご確認ください。無料体験は対象の方のみ。自動更新を継続しない場合は期間終了の24時間以上前にApp Storeから解約してください。

iCloud写真の削除は同期先にも反映されます。通常「最近削除した項目」で30日間復元できますが、完全削除など復元できない場合があります。空き容量の増加量は表示・保証しません。

キーワード候補：写真整理,重複,スクショ,カメラロール,スワイプ,写真管理

## 審査メモ
ログイン不要。写真アクセス→ホームのカテゴリ→写真選択→削除→OS確認。スワイプで候補に保存してから削除することも可能。限られた写真へのアクセスに対応。
購入・復元はPROボタン、管理は右上の設定→プラン。開発カタログとサンプル価格は配布バンドルに含まれない。

## 1.3追加機能
月別のサークルから仕分けを再開。大きい動画や画面収録を選んで整理。Proなら対応するSDR動画を圧縮し、見比べて保存できます。削除対象のサイズと端末の空き容量は分けて表示します。
