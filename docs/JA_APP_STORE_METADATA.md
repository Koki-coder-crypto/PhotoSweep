# App Store説明原稿（日本語、未提出）

名前: PhotoSweep
サブタイトル: スワイプで、写真に余白を
カテゴリ候補: 写真／ビデオ

写真整理、ちょっと楽しく。

残す。候補に入れる。スワイプで選んで、最後に確認。
PhotoSweepは、撮りためた写真を少しずつ見直すためのアプリです。

・まず20枚だけ。途中でやめても、続きから。
・月別やスクリーンショットから、見たい写真を選べます。
・左右のスワイプにも、ボタン操作にも対応。
・迷ったらスキップ。取り消しも無料です。
・削除候補に入れただけでは写真は消えません。候補を確認し、iPhoneの確認画面から削除します。
・すべて残した日も、見直した分を記録します。

写真を開発者のサーバーへ送りません。アカウント登録や広告SDKはありません。iCloud写真の読み込みには通信が必要な場合があります。

無料で1日50枚の新しい写真を仕分けできます。候補の確認・削除・取り消し・保存は、上限に達した後も無料です。

PhotoSweep Proでは仕分けの枚数制限を解除し、期間指定・並び替え・20/50/100枚の区切りを利用できます。月額または年額の自動更新サブスクリプションです。料金と無料体験の適用条件はアプリ内のApp Store情報をご確認ください。無料体験は対象の方のみ。継続しない場合は期間終了の24時間以上前にApp Storeから解約してください。

iCloud写真の削除は同期先にも反映されます。通常「最近削除した項目」で30日間復元できますが、完全削除など復元できない場合があります。空き容量の増加量は表示・保証しません。

キーワード候補: 写真整理,スクショ,カメラロール,スワイプ,写真管理,アルバム

## 審査メモ

ログイン不要。写真アクセス→月を選択→仕分け→候補確認→OSの削除確認の順に進めます。限られた写真へのアクセスでも動作します。削除は無料、スワイプのみでは削除しません。

購入・復元はPro画面、管理はマイページ→プランにあります。開発カタログ・サンプル料金は本番バンドルに含まれません。
