# PhotoSweep 1.2 — 触って理解できるオンボーディング

## 実装

導入を「はじめる → 比較の練習 → スワイプの練習 → 写真へのアクセス → 端末内解析の結果 → Pro案内」に変更。アクセス許可済みの画面は省略する。練習は飛ばせる。最後にホーム／スワイプ／削除候補の役割を一度案内する。

- カードが集まる600ms、画面切替240ms、選択140ms、候補への移動450ms。待機時間を演出のために追加しない。
- スワイプは指への追従、方向表示、退出、確定後のチェック。ボタンでも両方向を練習できる。
- 振動は選択／確定／成功を使い分け、100ms以内の重複を抑制。設定オフを尊重。音は既定でオフ。
- Reduce Motionは移動・回転を省き、短いフェードにする。説明はスクロールでき、主要ボタンは下部に固定する。
- サンプルは既存の提供デザイン素材 `handoff/design/assets/sea.jpg` を専用の `assets/onboarding/coast.jpg` に分離し、3種類の表示で使用。ユーザーの写真・録画を含めない。写真リポジトリ・実際の判断・無料枠・削除APIを練習から呼ばない。
- 解析の読み込み件数・処理済み件数・分類件数は既存解析器の実値。未完了のカテゴリは「解析中」、解析不可は「未確認」。ホームへ進んでも解析を継続する。写真未許可、0枚、読み込み失敗、解析不可では自動のPro案内を省く。

## 保存と課金

`src/domain/onboarding.ts` に版・段階・完了・練習結果・表示目的・ホーム案内の状態を定義。SQLiteの既存meta JSONへ追加し、判断テーブルや無料枠、整理セッションを消さずに移行する。旧版の `onboarded=true` でも版2が未完了なら一度表示する。各段階の保存失敗は先へ進めず再試行できる。起動時の移行保存に失敗した場合も既存の起動エラー処理で再試行する。

設定の「使い方を見る」は再体験として開始し、整理位置を変更せず、自動のPro案内を省く。導入終了後は自動再表示しない。初回のホーム案内を完了したら、通常整理の古い説明画面を重ねない。

Pro案内は操作体験と写真解析の後。購入・閉じる・無料継続・キャンセルのすべてが同じ保存済み完了処理へ進む。保留中は再購入を出さない。確認済みの購入・復元だけが成功演出の対象。既存Proは自動案内を省く。商品未設定／通信失敗では仮価格を出さず再試行・無料継続を表示する。週額／買い切りの総額、周期、体験資格と体験後料金はStoreKitに従う。Webカタログだけは明示した模擬料金。

## 開発と確認

- `npm run check`: 型、実SQLiteを使うロジック、Provider、画面、課金、保存、削除、解析の回帰検証とExpo診断。
- `npm run export:ios` → `npm run check:release-bundle`: Hermes出力と開発カタログ・模擬課金・デモ写真の除外検査。
- `http://localhost:8081/catalog`: O01〜O06が新しい6段階。従来70画面も維持。
- `tools/generate-route-types.cjs`: WindowsのMetro監視でルート型が空になる場合に備え、型検査前にExpo自身のジェネレーターで実際のappディレクトリから型を再作成する。
- ブラウザー確認の画像・ログはローカルの `artifacts/onboarding-qa/`。実機やStoreKit Sandboxの代替とは扱わない。

## iPhone 15での確認（実行待ち）

1. **既存アプリを削除せず上書きインストール**。1.2の導入が一度表示され、以前の候補と整理位置が残っていることを確認する。
2. 写真2枚を選んで確定し、左右に1回ずつスワイプ。ボタン操作も確認。振動が強すぎないか、指から遅れないか、説明が読めるかを見る。
3. 比較・スワイプ・解析・Proの各段階でアプリを強制終了して開き、続きから再開することを確認する。練習だけでは今日の無料枠を減らさない。
4. 許可済みなら許可画面を省略。新規／拒否／選択した写真のみはテスト用の許可設定で確認。端末にないiCloud写真は解析対象外となり得る。
5. 解析中に「解析を続けて先へ」。商品未設定なら料金エラーから「無料のまま続ける」でホームへ。導入完了後に再起動し、説明や自動課金画面が繰り返されないことを確認する。
6. 設定から再体験し、既存の整理位置を変えないことを確認。振動オフ／Reduce Motion／文字拡大／VoiceOverも確認する。
7. App Store Connectの商品設定後、Sandboxで体験資格あり／なし、購入キャンセル、保留、復元、確認済み購入を検証する。確認前に購入成功と判定しない。

触覚、実写真へのOS許可、100回の実機操作、Sandbox課金は端末操作が必要なため未実行。App Storeへの提出・公開は行わない。

自動検証結果：型検査、Node/SQLite 58件、Jest 140件、Expo診断21項目が成功。iOS Hermes出力と開発素材除外検査も成功。Webでは360／390／430幅、途中再読み込み、無料継続、設定からの再体験、完了後の再起動を確認。詳細は `docs/onboarding-verification.json`。端末での振動・追従・OS許可・Sandboxは別途実行待ち。
