# 無料・Pro（1.1.0）

| 機能 | 無料 | Pro |
|---|---|---|
| 新しい写真の判断・一覧からの候補登録 | 1日50枚 | 上限なし |
| 似ている写真・同じ画像・スクショの比較 | 利用可 | 利用可 |
| 保存済み候補の確認・削除・取り消し | 制限なし | 制限なし |
| スワイプの期間指定・並び替え | 月別を利用 | 任意指定 |
| スワイプの区切り | 20枚（残数以下） | 20 / 50 / 100枚 |

ユーザー提供のCleanup使用動画では約1:52に週1,500円・買い切り6,000円・対象者7日無料を確認した。PhotoSweepの設定候補もこの組み合わせとする。競合の現在価格や全ユーザー共通の価格を保証するものではない。App Store Connectの商品登録・承認は未確認。

- 自動更新：com.kokicoder.photosweep.pro.weekly。1週間、候補価格1,500円、対象者7日無料。
- 買い切り：com.kokicoder.photosweep.pro.lifetime。非消耗型、候補価格6,000円。自動更新・無料体験なし。
- 従来のmonthly / annual SKUは確認・復元の互換性を残す。新商品が取得できれば週額と買い切りを優先表示する。

製品版にサンプル価格は含めない。StoreKitから得たローカライズ価格、期間、体験資格を表示する。価格取得失敗では再読み込み・無料継続を案内する。資格不明の体験購入は無効。買い切りはStoreKitのnon-consumable型を検証する。

表示のタイミング：ホームのPRO、まとめて選んだ新規写真が残り無料枠を超える場合、スワイプ上限・Pro設定の利用時。閉じるボタンと無料継続を常設し、総額・更新周期を購入ボタン付近に表示する。最初の整理開始や保存済み候補の削除を購入で遮らない。

新規候補の一括登録は無料枠と同じSQLiteトランザクションで保存する。保存失敗で写真を削除しない。過去に判断済みの写真・同日の再選択は二重消費しない。日付・時計巻き戻し・Pro失効の既存規則を維持する。端末再インストールをまたぐ不正利用防止は、サーバーを持たない構成では保証しない。

権利はStoreKitの検証済みトランザクションに従う。保留・キャンセル・復元・更新停止・期限切れ・返金・猶予期間を区別する。買い切りも返金取消を反映する。
